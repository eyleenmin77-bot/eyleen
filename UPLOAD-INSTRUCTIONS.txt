Eyleen portfolio update — September 2026

1. Unzip the download on your Mac.
2. Open the unzipped folder. Select all the files INSIDE it, not the enclosing folder.
3. In the root of your GitHub eyleen repository, click Add file > Upload files.
4. Drag the selected files into GitHub, wait for the upload list, and commit changes.
5. The files index.html, styles.css, projects.html, Resume.pdf, and others with matching names will replace their older versions.
6. Wait for the GitHub Pages deployment to finish and reload the site. Open a fresh incognito window to test the loading screen, which runs once per browsing session.
